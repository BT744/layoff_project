Overview
This project is to provide a data cleaning walkthough for a set of dirty dataset. 

The goal is to explore patterns in spending habits, consumption levels for different products, preferred payment method and if weather will affect the transactions.

Skills Demonstrated
Summary of the dataset
Data cleaning by identifying missing values and remove columns and rows with null values
Filter by amount spent
Scatterplot
Bar graph
Box-and-whisker plot
Dataset
https://github.com/BT744/Global-Coffee-Analysis/blob/main/coffee_shop_sales.csv
How to Run
Open Python Jupiter Notebook
Download the coffee_shop_sales.csv file and ensure it is placed under the same folder as the Global Coffee Analysis.py folder.
Run the Python script
Execute analysis queries
